# Loan Default Prediction

A machine learning system that predicts whether a borrower will default on their first loan payment (FPD-15). It includes a full modelling pipeline in a Jupyter notebook and a Flask REST API for serving predictions. 

**Note**: The data used for this project is real anonymised historical data **that was provided publicly** by a leading African digital lender for the purpose of scoping out possibilities in loan default prediction.

---

## How it works

Raw loan application data is pulled from two credit bureaus (CB1 and CB2), a BVN lookup, salary service records, and a previous-application history. The pipeline:

1. **Feature engineering** — merges bureau fields (worst DPD wins, outstanding balances summed), derives loan age and customer age from dates, and flags whether a salary service or prior application exists
2. **Imputation** — fills numerical gaps with training-set column means; categorical gaps are filled post-encoding
3. **Outlier removal** — Local Outlier Factor (LOF) applied to continuous features of the training set only
4. **Class balancing** — Random oversampling on the training set to address the default/non-default imbalance
5. **Encoding** — Target encoding per categorical feature, fitted on training data
6. **Feature selection** — RFECV narrows the feature space; a correlation screening step removes redundant predictors
7. **Model** — Random Forest Classifier tuned via grid search with shuffled K-Fold CV
8. **Deployment** — trained artefacts serialised with joblib and loaded by a Flask API at startup

## Setup

Requires Python 3.10+. On macOS, xgboost needs the OpenMP runtime:

```bash
brew install libomp
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Running the notebook

The notebook trains the model end-to-end and writes all artefacts to `artifacts/`. Run it headlessly with:

```bash
cd src
jupyter nbconvert --to notebook --execute --inplace analysis.ipynb --ExecutePreprocessor.timeout=600
```

Or open it interactively with `jupyter lab`.

---

## Running the API

Start the Flask server from the project root (so relative paths to `artifacts/` resolve correctly):

```bash
cd loan_default_project
python src/app.py
```

The server listens on `http://127.0.0.1:5000`.

### `POST /predict`

Send a JSON body with the raw application fields. The API handles feature engineering internally.

**Example request**

```bash
curl -X POST http://127.0.0.1:5000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "CreationDate": "2024-03-01",
    "data.Request.Input.Customer.DateOfBirth": "1990-06-15",
    "data.Request.Input.Customer.Gender": 1,
    "data.Request.Input.Customer.ExistingCustomer": 0,
    "data.Request.Input.BVN.StateOfOrigin": "Lagos",
    "data.Request.Input.CB1.CurrentDPD": 0,
    "data.Request.Input.CB2.CurrentDPD": 0,
    "data.Request.Input.CB1.MaxDPD": 0,
    "data.Request.Input.CB2.MaxDPD": 0,
    "data.Request.Input.CB1.Outstandingloan": null,
    "data.Request.Input.CB2.Outstandingloan": null,
    "data.Request.Input.PrevApplication.LoanAmount": null,
    "data.Request.Input.SalaryService.MinimumBalance": null
  }'
```

**Response**

```json
{
  "prediction": "0: not default",
  "probability of default": 0.12
}
```
